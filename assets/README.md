# Assets Folder - Kishor Kumar Portfolio

This folder is used for static assets like your profile photo and PDF resume.

### 1. Profile Photo (`profile.jpg`)
- You can upload your photo directly in the browser using the **Change Photo / Upload** button on the website.
- If you want the photo to be permanently bundled with your code when deploying to GitHub Pages or Netlify:
  1. Save your professional photo in this folder as `profile.jpg` (or `profile.png`).
  2. In `js/config.js`, set `photo: "assets/profile.jpg"`.
  3. That's it!

### 2. Resume File (`Kishor_Kumar_Resume.pdf`)
- A placeholder resume has been created here: `assets/Kishor_Kumar_Resume.pdf`.
- When you are ready, simply copy your actual PDF resume into this folder with the name `Kishor_Kumar_Resume.pdf` (or update `resumeUrl` in `js/config.js` with your custom filename).
- The "Download Resume" and "View Resume" buttons on the website will instantly link to your updated PDF!
