Google Drive Picker Integration

Google Drive Integration Ready

Click the button below to launch the official Google Picker window and select your document.

Google Drive API Configuration Steps:

To import documents directly from Google Drive without manual downloading, Google requires an OAuth Client ID and API Key.

  1. Go to the Google Cloud Console.
  2. Enable the Google Drive API and Google Picker API.
  3. Create an OAuth 2.0 Client ID (Web Application) and authorize http://localhost:3000.
  4. Create an API Key under Credentials.
  5. Add them to your .env file: 
    GOOGLE_CLIENT_ID=your_client_id.apps.googleusercontent.com
GOOGLE_API_KEY=your_api_key
